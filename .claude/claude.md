● QuackNote プロジェクト概要
QuackNote は、AI を活用した B2B SaaS 型の議事録作成アプリケーションです。
コンセプト
  「録音 → Stop → 音声アップロード → Whisper で文字起こし → GPT 要約 → Slack 通知」の一連のフローを自動化し、会議内容を素早くまとめて共有できるサービスです。

  技術スタック
  ┌──────────┬───────────────────────────────────────────────┐
  │ レイヤー │                     技術                      │
  ├──────────┼───────────────────────────────────────────────┤
  │ Frontend │ Vue 3, Vite, Vuetify 3, TypeScript, Pinia     │
  ├──────────┼───────────────────────────────────────────────┤
  │ Backend  │ Ruby 3.3.9, Rails 7.1.5 (API mode), MySQL 8.x │
  ├──────────┼───────────────────────────────────────────────┤
  │ 認証     │ AWS Cognito (JWT)                             │
  ├──────────┼───────────────────────────────────────────────┤
  │ インフラ │ AWS (ECS Fargate, S3, RDS, DynamoDB), Docker  │
  ├──────────┼───────────────────────────────────────────────┤
  │ CI/CD    │ GitHub Actions                                │
  └──────────┴───────────────────────────────────────────────┘
  プロジェクト構造

  quack-note/
  ├── backend/          # Rails API サーバー

  ├── docker-compose.yml
  └── README.md

  開発状況

  Git の履歴から、以下の機能が実装済みまたは進行中です:
  - AWS Cognito 連携によるサインアップ/ログイン UI
  - DynamoDB 登録処理
  - ログイン失敗時のカウント機能
  - 認証情報の改修

  設計方針

  - マルチテナント対応: Workspace 単位でのデータ分離
  - AI ロジックの分離: OpenAI/Claude などのプロバイダーを差し替え可能な設計
  - スケーラビリティ重視: 将来の拡張を見据えた構成

  ローカル開発

  Docker Compose で起動できます:
  - フロントエンド: http://localhost:5173
  - バックエンド API: http://localhost:3000
